# FlapKap Growth & Activation Proposal

Interactive proposal prepared by Arigue, covering the growth operating model, eight workstreams, illustrative unit economics, a controlled 90-day pilot and management scorecard.

**[View the live proposal](https://flapkap-growth-proposal-arigue.inoveaposts.chatgpt.site/)**

## Files

- `index.html` — complete standalone proposal, with embedded styles and JavaScript. No dependencies or build step.

## View locally

Download this repository and open `index.html` in a browser.

## Updating

Edit `index.html` to update the proposal. Changes in this GitHub repository do not automatically update the existing live site; publish an updated version separately.

## Figures and assumptions

This repository preserves the content of the supplied proposal ZIP. Historical figures are stated in the proposal; the simulator contains illustrative assumptions and is not a forecast or approved budget. Contribution and ROI depend on Finance-validated inputs.
